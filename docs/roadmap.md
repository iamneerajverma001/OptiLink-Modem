# Development Roadmap

## Phase 1 — Foundation
- organize firmware into modular layers,
- centralize configuration,
- establish TX/RX telemetry.

## Phase 2 — Robustness
- improve packet recovery,
- add sequence awareness and reliability tracking,
- refine adaptive receiver behavior.

## Phase 3 — Advanced Modem Features
- add ACK and retransmission logic,
- improve PHY abstraction for alternate encodings,
- strengthen resilience under noisy conditions.

## Phase 4 — Portfolio Polish
- improve documentation,
- add diagrams and architecture notes,
- prepare a clean GitHub presentation.
