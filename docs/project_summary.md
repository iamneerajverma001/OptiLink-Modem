# Project Summary

## Vision

This project is a configurable STM32-based OptiLink modem system designed to demonstrate a modular optical communication link between a transmitter and a receiver.

## Technical Scope

- transmitter firmware for frame construction and optical output
- receiver firmware for signal acquisition and decoding
- configurable settings for timing, sync, and codec behavior
- UART telemetry for link diagnostics

## Why this is valuable

The design is intentionally structured to support future upgrades such as:
- stronger error correction
- ACK / retransmission mechanisms
- better adaptive filtering
- more advanced PHY schemes

## Portfolio Value

This repository can be presented as an embedded systems project showing:
- firmware architecture
- embedded signal processing
- real-time systems design
- communication protocol development
- documentation discipline
